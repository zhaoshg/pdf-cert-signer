# ADR-0001: 印章图片从外部提供改为支持系统自动生成

## 状态

已接受 (2026-08-01)

## 背景

当前 PDF 签章时，印章图片 URL 由调用方传入（`SignPosition.sealUrl`），系统仅做 HTTP 下载后原样嵌入。调用方需要自行准备、上传和管理印章图片，且印章图片与证书持有者身份的一致性完全由调用方负责。

## 决策

在保留外部传入 sealUrl 兼容模式的基础上，新增系统自动生成印章图片的能力。

### 类型区分

新增 `cert_type` 字段（1=企业，2=个人），在证书签发时由管理员指定：

- **企业证书 (cert_type=1)**：`credit_code` 存统一信用代码，印章为红色圆形公章
- **个人证书 (cert_type=2)**：`credit_code` 存身份证号，印章为个人方章

### 自动生成规则

| 证书类型 | 印章样式 | 内容 | 颜色 |
|---------|---------|------|------|
| 企业 (1) | 圆形公章 | 红色圆圈+中心五角星+`name` 沿上半弧分布+蓝色日期 | 红色宋体+蓝色日期 |
| 个人 (2) | 横排方章 | 楷体字体 `name` 单行居中+蓝色日期 | 黑色楷体+蓝色日期 |

- 背景：透明 PNG
- 日期格式：`yyyy-MM-dd`，取印章生成时的当前时间
- 生成位置：前端（Vue Canvas API），生成后转为 base64 data URL 随签章请求提交

### sealUrl 参数

从必填变为可选。不传时自动生成，传入时使用调用方提供的图片（兼容旧调用方）。

## 影响

- `IssueRequest` 新增 `certType` 必填字段
- `Certificate` 表新增 `cert_type` 列
- `SignPosition.sealUrl` 改为可选
- `CONTEXT.md` 中印章、签署人、证书签发相关描述已更新
- 前端 SignCanvas.vue 需要实现 Canvas 印章绘制逻辑（企业红章 + 个人方章）

## 替代方案

拒绝的方案：**完全移除 sealUrl 参数，强制自动生成** —— 不保留兼容性会导致已有调用方无法平滑迁移。
